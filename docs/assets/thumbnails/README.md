# Paper thumbnails

Place public paper-cover thumbnails here. Recommended filenames use the paper id, for example:

```text
splatam_2024.jpg
monogs_2024.png
```

The SVG files included in this template are placeholders. Replace them with low-resolution first-page screenshots, teaser figures, or official thumbnails before publishing.

Do not place private benchmark plots or unpublished test results in this folder because GitHub Pages publishes files under `docs/`.
